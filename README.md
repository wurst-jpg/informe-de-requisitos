# Informe de Requisitos — Guía de Entrega

> Documento de especificación de requisitos para el desarrollo de proyectos académicos. Basado en el formato establecido por CESDE.

---

## Estructura del Documento

El informe sigue el orden y formato definido por la institución. A continuación se detalla cada sección, su contenido esperado y la persona responsable de su redacción o formato.

| # | Sección | Responsable | Descripción |
|---|---------|-------------|-------------|
| 1 | Portada | **deerly** | Contenido centrado en el eje vertical. Incluye título del proyecto, nombre del estudiante, materia, tutor, institución y ubicación. |
| 2 | Tabla de contenido | **jose** | Debe ser auto-generada por el procesador de texto. |
| 3 | Listado de tablas | **mikey** | Índice de todas las tablas incluidas en el documento, con número y título. |
| 4 | Listado de ilustraciones | **mikey** | Índice de todas las ilustraciones/diagramas, con número y título. |
| 5 | Introducción | **catalina** | Describe qué contiene el documento, su propósito y cómo está organizado. Sirve como carta de navegación para las personas involucradas. |
| 6 | Objetivos | **hernan** | Redactados bajo la taxonomía de Bloom. Verbo en infinitivo, tercera persona. Se divide en: Objetivo General + Objetivos Específicos. |
| 7 | Planteamiento del problema | **hernan** | Contiene la necesidad, el manejo actual de la situación y la solución propuesta. Incluye tabla comparativa (Problema Actual → Consecuencia → Solución con la Aplicación). |
| 8 | Diagramas — Modelo Relacional | **hernan** | Diagrama que representa la estructura de datos y las relaciones entre las entidades del sistema. |
| 9 | Stack tecnológico | **jose** | Mención de las tecnologías y herramientas seleccionadas para la solución (frontend, backend, base de datos, etc.). |
| 10 | Alcance | **derly** | Define el entregable del proyecto. |
|   | — Inclusiones | **derly** | Qué se entregará al finalizar el proyecto (módulos, funciones, features). |
|   | — Exclusiones | **derly** | Qué NO se entrega, resuelve o desarrolla en esta versión. |
| 11 | Conclusiones | **jose** | Reflejan el trabajo del equipo de desarrollo del documento. |
| 12 | Glosario | **catalina** | Términos redactados en lenguaje técnico y no técnico para alinear vocabularios. |
| 13 | Referencias | **catalina** | Documentos y fuentes consultadas, bajo sangría francesa. |
| 14 | Propiedad intelectual del estudiante | **jose** | Declaración de autoría del estudiante. |
| 15 | Derechos y distribución del CESDE | **jose** | Normas de distribución del documento bajo la institución. |
| 16 | Proyecto formativo meramente académico | **jose** | Aclaración de carácter académico del proyecto. |

---

## Formato General

| Elemento | Especificación |
|----------|----------------|
| **Tipografía** | Times New Roman 12pt **o** Arial 11pt — responsable: **mikey** |
| **Color de texto** | Negro, en todo el documento |
| **Párrafo** | Sangría de primera línea de 1.27 cm — responsable: **deerly** |
| **Interlineado** | Doble o múltiple — responsable: **mikey** |
| **Tabla de contenido** | Auto-generada — responsable: **jose** |
| **Portada** | Contenido centrado en eje vertical — responsable: **deerly** |
| **Referencias** | Sangría francesa — responsable: **catalina** |
| **Glosario** | Términos en lenguaje técnico y no técnico — responsable: **catalina** |
| **Objetivos** | Taxonomía de Bloom, verbo en infinitivo, tercera persona — responsable: **hernan** |
